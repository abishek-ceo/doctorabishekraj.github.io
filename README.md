# Abishek Hospital website: abishekhospital.com

Fast, mobile-first, multi-page static website for **Abishek Hospital, Erode Fort** (Dr. Jayanthi Prabakaran).
Hosted on GitHub Pages from the `main` branch; the custom domain is set by the `CNAME` file (never delete it).

## How it is organised

| Path | What it is |
|---|---|
| `index.html`, `*/index.html`, `404.html`, `privacy-policy.html` | **Generated pages.** Do not edit by hand; they are overwritten by the builder. |
| `tools/site.mjs` | Hospital facts (address, phone, hours, social links, stats, service list). Change a fact here once and it updates everywhere. |
| `tools/pages/*.mjs` | The words on each page (home, service pages, doctor, videos, contact, FAQ, gallery, privacy). |
| `tools/lib.mjs` | Shared header, footer, buttons, SEO tags and structured data (JSON-LD). |
| `assets/css/site.css`, `assets/js/*.js` | Styling and the tiny scripts (menu, map, WhatsApp booking form, gallery viewer). |
| `assets/fonts`, `assets/img` | Self-hosted fonts and optimised images (generated by `tools/make-images.py`). |
| `sitemap.xml`, `robots.txt`, `assets/icons.svg` | Generated by the builder. |
| `sw.js` | Intentionally a **self-removing service worker**. An early version of the site cached pages forever; this file cleans that up for old visitors. Keep it. |

## Everyday commands

```bash
node tools/build.mjs     # regenerate all pages, sitemap and icon sprite (Node 18+, no dependencies)
node tools/check.mjs     # verify links, anchors, icons, JSON-LD, titles/descriptions, sitemap
```

Typical edit: change the text in `tools/pages/...`, run the two commands above, commit everything (generated files included), merge to `main`.

## Hospital photos

1. Put your own photos (jpg/png/webp) in a `photos/` folder. Use the **original full-size files** (ideally 1600 px or wider). Photos narrower than about 900 px, such as small Google Maps thumbnails, are shown at natural size with no click-to-enlarge, because enlarging them looks blurry. Avoid patients and newborns unless you hold written consent.
2. `python3 tools/make-images.py` (needs Pillow, numpy, scipy). It resizes to 480/960/1600 px WebP and strips location data (EXIF/GPS).
3. Add a line per photo in `photos/captions.json`: `{"file-name-without-extension": {"alt": "...", "caption": "...", "order": 1}}`.
4. Run the build. A Gallery page, menu entry and a home-page photo strip appear automatically when photos exist.

## Notes

- No cookies, analytics or third-party scripts load by default. Google Maps loads only after a visitor taps "Show map".
- The booking form opens WhatsApp (or email) with the details pre-filled; nothing is stored on the website.
- Add another social profile in `tools/site.mjs` (`social`) and add its icon to `tools/icons.json` if needed.
- `assets/img/og-image.jpg` is the WhatsApp/Facebook share preview; its template is `tools/og-template.html`.
