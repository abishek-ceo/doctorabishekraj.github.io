# Abishek Hospital website: abishekhospital.com

Fast, mobile-first, multi-page static website for **Abishek Hospital, Erode Fort** (Dr. Jayanthi Prabakaran).
Hosted on GitHub Pages from the `main` branch; the custom domain is set by the `CNAME` file (never delete it).

## How it is organised

| Path | What it is |
|---|---|
| `index.html`, `*/index.html`, `404.html`, `privacy-policy.html` | **Generated pages.** Do not edit by hand; they are overwritten by the builder. |
| `tools/site.mjs` | Hospital facts (address, phone, clinic hours and holiday dates, social links, stats, service list). Change a fact here once and it updates everywhere. |
| `tools/pages/*.mjs` | The words on each page (home, service pages, doctor, videos, contact, FAQ, gallery, privacy, and the two patient tools in `tools.mjs`). |
| `tools/lib.mjs` | Shared header, footer, buttons, SEO tags and structured data (JSON-LD). |
| `assets/css/site.css`, `assets/js/site.js`, `assets/js/tools.js` | Styling and the tiny scripts: `site.js` (menu, map, video, WhatsApp booking form, live "Open now" line, count-up numbers) runs on every page; `tools.js` (due-date calculator, visit reminder) loads only on the two tool pages. |
| `doctor.png`, `hospital-logo.png` | Original brand images. The previous site used them as its share image and logo, so other sites may still link to them: keep them. `doctor.png` is also the source for the portrait made by `tools/make-images.py`. |
| `assets/fonts`, `assets/img` | Self-hosted fonts and optimised images (generated by `tools/make-images.py`). |
| `sitemap.xml`, `robots.txt`, `assets/icons.svg` | Generated by the builder. |
| `sw.js` | Intentionally a **self-removing service worker**. An early version of the site cached pages forever; this file cleans that up for old visitors. Keep it. |

## Everyday commands

```bash
node tools/build.mjs     # regenerate all pages, sitemap and icon sprite (Node 18+, no dependencies)
node tools/check.mjs     # verify links, anchors, icons, JSON-LD, titles/descriptions, sitemap
```

Typical edit: change the text in `tools/pages/...`, run the two commands above, commit everything (generated files included), merge to `main`.

## Hospital photos

1. Put your own photos (jpg/png/webp) in a `photos/` folder. Use the **original full-size files** (ideally 1600 px or wider); small Google Maps thumbnails look blurry. Photos are shown at their natural size. Avoid patients and newborns unless you hold written consent.
2. `python3 tools/make-images.py` (needs Pillow, numpy, scipy). It resizes to 480/960/1600 px WebP and strips location data (EXIF/GPS).
3. Add a line per photo in `photos/captions.json`: `{"file-name-without-extension": {"alt": "...", "caption": "...", "order": 1}}`.
4. Run the build. A Gallery page, menu entry and a home-page photo strip appear automatically when photos exist.

## Notes

- A click-to-enlarge photo viewer existed until commit `186f005`; it was removed because the current photos are too small to enlarge. Restore it from that commit if full-size photos arrive.
- `node tools/check.mjs` also fails if an image, font or script in `assets/` is not used by any page, stylesheet or the manifest, so leftovers are caught early.
- The "Write a Google review" links use `reviews` in `tools/site.mjs`.
- **Patient tools:** `/pregnancy-due-date-calculator/` (indexed) and `/visit-reminder/` (not indexed, not in the sitemap). Both run in the visitor's browser and nothing typed in is sent or stored. On the reminder page, staff can fill in the date and time and tap "Send on WhatsApp": the link carries only the date, time and visit type, and opens pre-filled on the patient's phone. Clinic hours come from `hours` in `tools/site.mjs`.
- **Open now line:** the home and contact pages show "Open now · until 6:30 PM" or "Closed now · opens tomorrow 9:00 AM". `site.js` works it out from `hours` in `tools/site.mjs` (`days`, `open`, `close`) using Indian time, whatever time zone the visitor is in, and refreshes it every minute. It reads the visitor's own phone clock, so a phone with a wrong clock shows a wrong line. **Add public-holiday dates to `closedOn`** (for example `['2026-11-08']`) and rebuild, otherwise the line says "Open now" on a day the clinic is shut. The reminder page also warns about those dates. Without JavaScript the line is simply not shown.
- **Speed and motion:** browsers that support it fetch a page when its link is hovered or pressed (speculation rules in `tools/lib.mjs`), and fade between pages while the header and phone action bar stay put (View Transitions, CSS). A reading-progress line under the header and the fade-up of cards as they scroll into view are CSS only (scroll-driven animations; browsers without support just show the content). `site.js` adds the count-up in the experience band. All of it sits in one block of `site.css` (`motion`) that is switched off for visitors who ask their device for reduced motion and when printing; browsers without support simply skip it, so no content depends on it. Keep new moving parts inside that block. New CSS properties such as `animation-timeline` and `@view-transition` are valid but unknown to the W3C CSS validator, so it reports them; the page HTML validates cleanly.
- No cookies, analytics or third-party scripts load by default. Google Maps loads only after a visitor taps "Show map".
- The booking form opens WhatsApp (or email) with the details pre-filled; nothing is stored on the website.
- Add another social profile in `tools/site.mjs` (`social`) and add its icon to `tools/icons.json` if needed.
- `assets/img/og-image.jpg` is the WhatsApp/Facebook share preview; its template is `tools/og-template.html`.
- Videos use a click-to-play card (nothing loads from YouTube until it is tapped). The embedded video is `featuredVideo` in `tools/site.mjs`; only add video IDs that are confirmed to be on the hospital's own channel, then run the build.
